# FUTURE_FS_03 - Local Business Website

## Hepsi Café Website ☕

This project was developed as part of the **Future Interns Full Stack Web Development Internship**.

---

## 📌 Project Overview

Hepsi Café is a professional responsive website created for a local café business.

The website helps the business build an online presence by displaying its services, menu items, gallery, and contact information.

---

## 🎯 Business Problem

Many small local businesses do not have an online presence, making it difficult for customers to discover their products, services, and contact details.

---

## 💡 Solution

A responsive website was developed to help customers:

- Learn about the café
- View menu items
- Explore café images
- Contact the business easily

---

## ✨ Features

- Responsive Design
- Home Section
- About Section
- Menu Section
- Gallery Section
- Contact Form
- Smooth Scrolling
- Mobile Friendly Layout

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
