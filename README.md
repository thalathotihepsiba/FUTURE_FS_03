# 📌 Project Overview

Hepsi Café is a modern, responsive website developed for a local café business. The website helps customers explore the café, browse the menu, view the gallery, and contact the business easily from any device.

---

# 🎯 Business Problem

Many small local businesses do not have an online presence, making it difficult for customers to discover their services, menu, location, and contact information.

---

# 💡 Solution

A responsive website was created to help customers:

- Learn about the café
- View food and beverage menu
- Explore the café gallery
- Contact the café easily
- View the café location through Google Maps
